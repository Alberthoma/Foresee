## Modificaciones realizadas

### 1. Inicialización de App Check (`js/firebase.js`)
- **Tipo:** INSERCIÓN
- Import de `initializeAppCheck`/`ReCaptchaV3Provider` desde el mismo CDN y versión (11.6.1) que el resto del SDK.
- Nueva constante `APP_CHECK_SITE_KEY` (clave pública, no secreta — mismo criterio que `FIREBASE_CONFIG`).
- `initializeAppCheck(firebaseApp, { provider: new ReCaptchaV3Provider(APP_CHECK_SITE_KEY), isTokenAutoRefreshEnabled: true })`, llamado justo después de crear `firebaseApp` y antes de `getAuth`.
- **Por qué:** único punto de import de Firebase en la app (`firebase.js`), mantiene el patrón existente.
